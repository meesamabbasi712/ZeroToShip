# Doom Folder - CLI Storage Analyzer

## Project Overview

Doom Folder is a command-line storage analyzer developed in Python. It scans folders recursively and analyzes stored files. The application detects large files, old files, screenshots, archive files, duplicate files, and empty folders through a simple command-line interface.

The project helps users understand their storage usage and identify unnecessary files that may consume disk space.

## Problem Statement

Managing large numbers of files and folders manually is difficult. Users often struggle to find large files, duplicate files, old files, and unnecessary folders.

## Proposed Solution

Doom Folder provides an automated solution by scanning directories, collecting file information, analyzing storage usage, and categorizing files into different groups through an interactive CLI system.

## Features

- Recursive directory scanning
- File information extraction
- Storage Summary Dashboard
- Large File Detection
- Old File Detection
- Screenshot Detection
- Archive File Detection
- Duplicate File Detection
- Empty Folder Detection
- File Sorting and Filtering
- Interactive CLI Menu
